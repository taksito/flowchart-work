當 🏁 被點擊 when flag clicked

What changes between the two 兩邊哪裡不一樣想法一樣，寫法有一點點不同

④Flowchart asks finger ≤ n ? and keeps going while True. Scratch's repeat until finger > n stops when True. 流程圖是「是就繼續」；Scratch 是「直到成立就停」，所以條件要反過來。
⑤set sum to (sum + finger)：綠色的運算積木裡放 sum 變數 和 finger 變數。變數裡面可以放變數的值！
⑥change finger by 1 就是 finger = finger + 1，手指往右一格。
↺The loop arrow in the flowchart = the C-shaped repeat block in Scratch. 流程圖繞回去的箭頭，就是 Scratch 的 C 形重複積木。
