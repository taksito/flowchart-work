Password Check 密碼檢查

Grade 7 · Scratch · 1 lesson　七年級資訊科技｜用流程圖規劃，再到作業網站的 Scratch Lab 做出「輸入密碼、最多試三次」的程式

1 Demo 示範2 Plan 想一想3 Draw 畫流程圖4 Flowchart × Blocks 對照5 Build 拼拼看6 Challenge 挑戰

1. Demo 示範：做出來會長怎樣？

按綠旗開始。程式會問你密碼，答對就說「歡迎使用本系統」；連續答錯三次，帳號就被鎖定。

示範密碼：137
count 1
Path 執行路徑：按綠旗後，這裡會顯示程式走過流程圖的哪幾步。

Try it 試試看

  1. 輸入正確密碼 137，看看會發生什麼事。
  2. 重新按綠旗，故意連續打錯三次。
  3. 打錯一次、第二次答對，可以嗎？
  4. 注意左上角的 count：一開始是幾？什麼時候會加 1？

下方的「執行路徑」編號，對應第 4 段流程圖上的編號。

2. Plan 想一想：程式需要什麼？

先別急著拖積木。先想清楚：程式要「收到什麼」、「做什麼判斷」、「顯示什麼」。

INPUT 輸入

使用者打的密碼，會存在 answer 答案 裡。

PROCESS 處理

比對 answer 和 password；答錯就把 count 加 1，再問一次，直到答對或 count 到 3。

OUTPUT 輸出

密碼錯誤／歡迎使用本系統／輸入密碼錯誤3次，帳號已被鎖定。

Variable 變數Starts at 起始值Used for 用途
password137正確的密碼，用來比對
count1現在是第幾次輸入。第一次輸入時就是 1，所以 count = 3 代表已經是第 3 次

3. Draw 流程圖怎麼畫

用五種符號。重複的部分用 LOOP 重複（六邊形），DECISION 判斷 只在最後分辨結果時用。

START / END
開始／結束
INPUT / OUTPUT
輸入／輸出
PROCESS
處理
DECISION
判斷
LOOP
重複
  1. Start and set up 開始與準備：START 之後，用兩個處理框設定 password = 137 和 count = 1。
  2. Ask 詢問：畫一個 INPUT，讓使用者輸入密碼，存進 answer。
  3. Repeat 重複：畫一個 LOOP（六邊形），寫 repeat until answer = password or count = 3：重複，直到答對或已經第 3 次。
  4. Inside the loop 重複要做的事：從 LOOP 拉出「repeat 重複」的線：OUTPUT「密碼錯誤」→ count = count + 1 → 再一個 INPUT「請輸入密碼」，最後拉線回到 LOOP。
  5. After the loop 重複結束後：從 LOOP 拉出「done 完成」的線，接一個 DECISION：answer = password？是就輸出「歡迎使用本系統」，否就輸出「輸入密碼錯誤3次，帳號已被鎖定」，最後到 END。

6. Challenge 挑戰

剩下幾次？

答錯時說出「密碼錯誤，還剩 2 次」。提示：用 join 字串組合 和 3 − count。

為什麼是 = 3？

如果條件寫成 count > 3，使用者總共會被問幾次？用第 1 段的想法推推看。

流程圖先改

想讓次數上限改成 5 次，流程圖要改哪一格？積木要改哪一個？訊息裡的「3次」也要改嗎？

Teacher notes 教師備課：45 分鐘流程
Time 時間Activity 活動
5 分第 1 段示範：全班一起試正確密碼、錯三次，觀察 count 和執行路徑

12 分第 3 段：學生在流程圖畫板照五個步驟畫出流程圖
18 分第 4、5 段：對照編號找積木，在作業網站 Scratch Lab（scratch-pw）拼出程式、測試並繳交
5 分分享與挑戰：完成的學生做第 6 段挑戰
