Loading blocks… 積木載入中…
Press Run to try your program. Tick ☐ next to a variable to watch it. 按 Run 執行；在變數旁點 ☐ 可以在舞台上看到它的值。
Helper 小幫手

    New variable 建立變數

    Download work file 下載作業檔

    Type your class, number and name, then download. 填好班級、座號與姓名後按「下載」，會存成一個 .json 檔，下次用「開啟檔案」就能接著做。

    Open work file 開啟檔案

    Choose a .json file you downloaded before. Your current blocks will be replaced. 選擇之前下載的 .json 檔，目前的積木會被取代。

    Check my program 提交批改

    Tests 測試

    Certificate 完成圖

    Submit to your teacher 繳交作業

    Your program goes straight to your teacher's Google Drive. You can submit again later; the newest one replaces the old one. 作品會直接送到老師的 Google Drive，之後可以再交一次，新的會取代舊的。
