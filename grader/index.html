BMI 流程圖評分標準（滿分 100）

越接近標準答案分數越高。除了檢查有沒有畫對符號，也會把學生的流程圖真的「跑一遍」，看每種 BMI 會不會輸出正確結果。

項目檢查內容配分
Structure 結構有 START、有 END、能從開始走到結束、每個圖形都有接線、每個判斷都有 Yes／No 兩條路20
Input 輸入輸入身高、輸入體重，並使用輸入／輸出符號10
Process 計算用處理符號計算 BMI，公式等於 體重 ÷ 身高²（身高用公分時要先 ÷100）10
Decision 判斷菱形判斷中有 18.5、24、27 三個分界值20
Output 輸出用輸入／輸出符號輸出 thin、normal、overweight、obesity10
Test run 執行測試8 個 BMI 測試值：16、18.4、18.5、22、24、25.5、27、32，各算 2 次（直接給 BMI 測判斷、輸入身高 1.6 公尺與對應體重測整個流程）30
English 英文不計分，只鼓勵：顯示英文使用率，全英文的作品標上 EN；用了中文會列出可以換成的英文，例如 身高 → height、是 → Yes。0

判斷的寫法不限：「BMI < 18.5」、「BMI ≥ 27」、「18.5 ≤ BMI < 24」、中文「小於」「大於等於」都看得懂；判斷順序由大到小或由小到大都可以。分界值剛好等於 24 算 overweight，等於 27 算 obesity。

Scratch BMI 積木程式評分標準（滿分 100）

題目：當綠旗被點擊時，詢問身高和體重並存進變數，計算 BMI，依 18.5、24、27 說出 thin、normal、overweight、obesity。批改時會真的執行學生的程式，自動回答身高 1.5 公尺和八組體重；身高用公分寫也能自動判斷。

項目檢查內容配分
Structure 結構有「當綠旗被點擊」、沒有散落的積木、有用「如果…那麼…否則」15
Input 輸入詢問身高和體重（各 4 分），答案存進變數（7 分）15
Process 計算變數裡算出正確的 BMI（weight / (height × height)）20
Decision 判斷條件裡有 18.5、24、27 三個分界值20
Output 輸出說出 thin、normal、overweight、obesity10
Test run 執行測試八組 BMI：16、18.4、18.5、22、24、25.5、27、3220

Scratch Pass or Fail 積木程式評分標準（滿分 100）

題目：當綠旗被點擊時，詢問四個成績並存進變數，算出總分和平均，平均 ≥ 60 說 pass，否則說 fail。批改時會真的執行學生的積木程式，自動回答八組成績。

項目檢查內容配分
Structure 結構有「當綠旗被點擊」、沒有散落沒接上的積木、有用「如果…那麼（否則）」15
Input 輸入詢問四次（每次 2 分），每次把 answer 存進變數15
Process 計算總分（四個相加）10 分、平均（÷ 4）10 分；直接算平均也算對20
Decision 判斷「如果」的條件和 60 比較（10 分），而且用到平均（5 分）15
Output 輸出有說 pass 和 fail10
Test run 執行測試8 組成績實際執行，含平均剛好 60、59.7525

Scratch 沒有「≥」，所以常見正確寫法是「如果 avg < 60 那麼 說 fail 否則 說 pass」；寫成「avg > 59.99」或「not (avg < 60)」也算對。

1 加到 n 流程圖評分標準（滿分 100）

題目：輸入一個數 n，用迴圈算出 1 + 2 + … + n 並輸出總和。批改時會把學生的流程圖真的「跑一遍」，輸入 n = 1、2、3、4、5、10、20、100，檢查輸出是不是 1、3、6、10、15、55、210、5050。

項目檢查內容配分
Structure 結構有 START、有 END、能從開始走到結束、每個圖形都有接線、判斷有 Yes／No 兩條路；方向拉反或停不下來的迴圈（紅線）每條扣 2 分20
Input 輸入輸入 n，並使用 INPUT 符號10
Process 計算設定初始值 sum = 0、i = 1（5 分）、累加 sum = sum + i（10 分）、計數 i = i + 1（10 分）25
Loop 迴圈判斷和 n 比較（例如 i <= n）、有線回到判斷形成迴圈、條件寫在菱形裡15
Output 輸出用 OUTPUT 符號輸出總和5
Test run 執行測試8 個 n 實際跑一遍25

寫法不限：sum += i、i++、倒數（i = n，i > 0，i = i − 1）、判斷寫 i > n 再把 Yes／No 對調都算對；8 個測試全對時，計算和判斷都給滿分。只用公式 n × (n + 1) ÷ 2、沒有迴圈的話，答案雖然對，「形成迴圈」這一項不給分，也不會得到完成圖。常見錯誤會直接提示：用 i < n 會少加最後一個數、輸出 i 而不是 sum、少了 i = i + 1 讓迴圈停不下來。

Scratch 1 加到 n 積木程式評分標準（滿分 100）

題目：當綠旗被點擊時，詢問 n 並存進變數，用重複積木把 1 到 n 加起來，最後說出總和。批改時會真的執行程式，自動回答 n = 1、2、3、4、5、10、20、100，看說出的最後一個數字對不對（say 5050 或 say "Sum: 5050" 都可以）。

項目檢查內容配分
Structure 結構有「當綠旗被點擊」、沒有散落的積木10
Input 輸入詢問 n（8 分），把 answer 存進變數（7 分）15
Process 計算迴圈裡累加 change sum by (i)（10 分）、計數 change i by 1（10 分）20
Loop 迴圈使用 repeat 或 repeat until（10 分），重複次數或條件用到 n（10 分）20
Output 輸出用 say 說出總和10
Test run 執行測試8 個 n 實際執行25

常見正確寫法：set sum to 0、set i to 0、repeat (n) { change i by 1、change sum by (i) }、say (sum)。也可以 i 從 1 開始、先加再加一；用 repeat until (i > n) 也可以。

Pass or Fail 成績及格判斷評分標準（滿分 100）

題目：輸入四個成績，算出總分與平均，平均 ≥ 60 輸出 pass，否則輸出 fail（剛好 60 算 pass）。會把學生的流程圖真的「跑一遍」。

項目檢查內容配分
Structure 結構有 START、有 END、能從開始走到結束、每個圖形都有接線、判斷有 Yes／No 兩條路20
Input 輸入輸入四個成績（每個 2 分），並使用 INPUT 符號10
Process 計算計算總分（四個成績相加）10 分、計算平均（總分 ÷ 4）10 分；直接寫 avg = (a+b+c+d)/4 也算對20
Decision 判斷用平均和 60 比較，條件寫在菱形裡15
Output 輸出用 OUTPUT 符號輸出 pass 和 fail10
Test run 執行測試8 組成績實際跑一遍，含平均剛好 60、59.75 的邊界情況25
English 英文不計分，只鼓勵。0

變數名稱不限：s1～s4、a～d、score1～score4，或 國文、數學 都可以；可以一個 INPUT 放一個成績，也可以在一個 INPUT 裡寫 s1, s2, s3, s4。判斷寫 avg >= 60（Yes 接 pass）或 avg < 60（Yes 接 fail）都可以。

雙語課程鼓勵學生多用英文：英文不加分也不扣分，中文寫法一樣可以拿滿分；評語會稱讚全英文的作品，並建議其他人可以換成哪些英文字。

等第：90 分以上 優秀，75 分以上 良好，60 分以上 及格，60 分以下 需加強。
